### 1. Simplify Key Loading with Dispatch Table
Replace the nested `if/elif` in [`server.py:152`](server.py:152):

```python
# Current (nested if/elif checking PEM headers):
def _get_ssh_client(target):
    key_path = os.path.expanduser(target["auth"]["key_filename"])
    with open(key_path) as f:
        key_data = f.read()
    if "BEGIN OPENSSH PRIVATE KEY" in key_data:
        key = paramiko.Ed25519Key.from_private_key(open(key_path))
    elif "BEGIN RSA PRIVATE KEY" in key_data:
        key = paramiko.RSAKey.from_private_key(open(key_path))
    elif "BEGIN PRIVATE KEY" in key_data:
        key = paramiko.Ed25519Key.from_private_key(open(key_path))
    ...

# New (dispatch table):
_KEY_LOADERS = {
    "BEGIN OPENSSH PRIVATE KEY": lambda f: paramiko.Ed25519Key.from_private_key(f),
    "BEGIN RSA PRIVATE KEY": lambda f: paramiko.RSAKey.from_private_key(f),
    "BEGIN PRIVATE KEY": lambda f: paramiko.Ed25519Key.from_private_key(f),
}

def _load_ssh_key(key_path: str):
    """Load SSH private key using dispatch based on PEM header."""
    with open(key_path) as f:
        header = f.readline().strip()
    loader = _KEY_LOADERS.get(header)
    if not loader:
        raise SSHError(f"Unsupported key format: {header}")
    with open(key_path) as f:
        return loader(f)

def _get_ssh_client(target):
    key = _load_ssh_key(target["auth"]["key_filename"])
    ...
```

Add comment explaining each key format:
- `OPENSSH PRIVATE KEY` — Ed25519 keys generated by `ssh-keygen -t ed25519`
- `RSA PRIVATE KEY` — Legacy RSA keys (PKCS#1)
- `PRIVATE KEY` — Generic PKCS#8 format (could be Ed25519 or RSA)
